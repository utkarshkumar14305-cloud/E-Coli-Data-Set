# E. coli Protein Data Analysis

This project performs basic Exploratory Data Analysis (EDA) on the E. coli protein dataset using Python, Pandas, NumPy, and Matplotlib. It was created as part of HCL Python Training.

## Dataset
- **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/39/ecoli)
- **Total Records:** 336
- **Numerical Features:** 7
- **Protein Localization Classes:** 8

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Objectives
1. Count records in each protein localization class.
2. Calculate mean, median, minimum, and maximum values.
3. Identify the class with the highest number of records.
4. Compare average numerical values across classes.
5. Find records with the highest values in a selected column.
6. Check for missing values and duplicate records.

## Visualizations
- Bar chart showing protein class distribution.
- Histogram showing the distribution of AAC values.

## Key Observations
- The dataset contains 336 protein records across 8 localization classes.
- The `cp` class has the highest number of records (143).
- Different protein classes show variations in numerical features.

## Conclusion
This project helped me understand how to explore, analyze, and visualize real-world datasets using Python libraries.
